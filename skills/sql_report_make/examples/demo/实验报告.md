<section name="1．实验目的：">
掌握用 SQL 数据定义语言（DDL）创建数据库、表、索引和完整性约束的方法，理解主键、外键与唯一约束在数据一致性中的作用。
</section>

<section name="实验内容和要求：">
1. 创建数据库 S，字符集设为 utf8mb4，并切换为当前库；
2. 创建供应商表 S 与零件表 P，为每张表设置主键约束；
3. 为 P 表的 PNAME 列建立唯一索引，再用 DROP INDEX 删除；
4. 用 DROP TABLE 清理实验对象。

| 表名 | 含义 | 主键 |
| --- | --- | --- |
| S | 供应商 | SNO |
| P | 零件 | PNO |
</section>

<section name="实验重点和难点：">
重点是**主键与外键的差别**：主键唯一标识一行且不允许为空，外键只是引用另一张表的主键。难点是建表顺序——必须先建被引用表（S、P），再建有外键的 SPJ 表，否则会报 1452 外键约束错误。
</section>

<section name="实验程序：">
第一步：建库并切换到实验库。

```sql
CREATE DATABASE S;
```

执行结果：`Query OK, 1 row affected`。

第二步：建表，主键写在列定义之后。

```sql
CREATE TABLE S (SNO CHAR(4) NOT NULL, PRIMARY KEY (SNO));
```
</section>

<section name="实验总结：">
本次实验用 `CREATE DATABASE`、`CREATE TABLE`、`CREATE INDEX` 完成了数据库与表结构的定义，验证了主键的唯一性约束：插入重复学号时数据库直接拒绝。
---
建表顺序是最容易出错的地方，以后写脚本时把被引用表放在前面即可避免外键报错。
</section>
